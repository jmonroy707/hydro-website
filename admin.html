Publishing changes

  1. Make your edits.
  2. Click Save Draft if you want to keep working later on this device.
  3. Click Publish Website. Your authenticated session is verified by the server before any GitHub update is allowed.
  4. If publishing directly, GitHub Pages will rebuild from the committed change.

The editor does not store GitHub credentials or repository tokens.
